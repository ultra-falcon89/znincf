Developer: Frank Vaughn

Hanger Span names the pipe run whose span passes the mark for that size. Drag the span. A span under 0.6 m is not stored. Changing the size does not rewrite the stored span. The last run stays.

The app works offline. It does not ask you to sign in and it has no purchases.

To dismiss the keyboard on the run name, tap Done above the keyboard, or tap the empty page.

Write to frank.vaughn35@163.com if a run will not stay or the call does not change.
